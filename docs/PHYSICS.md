## 3. 三个前置验证：为什么这么实现

这三项不是「测一下放心」，而是**决定了实现方案**。原始数据在 `scripts/validate/`，跑 `npm run validate` 复现。

### 3.1 接触对摩擦可以覆写

| 配置 | 3 s 位移 | 末速度 |
|---|---|---|
| μ=0（对照） | 6.000 m | 2.000 m/s |
| μ=0.9（对照） | 0.223 m | 0 |
| 两侧 fixture μ=0.9，pre-solve 覆写为 0 | 6.000 m | 2.000 m/s |

pre-solve 回调被调用 721 次，覆写后行为与 μ=0 完全一致。**所以摩擦可以按「接触对（材质对）」设，
不用降到物体级**——`sqrt(μA·μB)` 混合 + 接触对覆写这条路成立，UI 才敢写「接触面摩擦因数」。

### 3.2 Canvas 2D 画得动 40 个挤出形状

桌面 Chrome（1280×800 @DPR2，无 WebGL）：**119 fps 空闲 / 84 fps 同时开模拟器**，
平均帧时 8.4–11.9 ms，p95 8.70 ms。这是桌面数据，**不能替代真机**——手机 Canvas2D 大约 30–60 fps。
但 116 fps 的余量说明瓶颈不在绘制本身，真机风险主要来自 DPR 3 与高频文字重排；
实现里预留了降级位（关阴影 → 关厚度 → 减采样）。

### 3.3 洛伦兹力必须用速度旋转，不能加力

| 积分方式 | 步长/子步 | 10 圈半径漂移 |
|---|---|---:|
| `applyForceToCenter(qv×B)` | 1/240 × 2 | **+12.50%** |
| 同上 | 1/240 × 1 | +26.57% |
| 同上 | 1/60 × 1 | +155.86% |
| **速度旋转（Boris 纯磁场形式）** | 1/240 × 2 | **0.0000%** |

原因：洛伦兹力永远垂直于速度，是「陀螺力」。显式/半隐式欧拉每步把速度向量拉长 `sqrt(1+(ωdt)²)` 倍，
误差随步数累积——**减小步长只能线性改善，治不了根**。

修正：二维里 `qv×B` 就是绕 B 轴的精确旋转，角度 `θ = −(q/m)·Bz·dt`。直接旋转速度向量，模长严格不变。
电场仍用半程冲量，两者可组合成完整 Boris 格式。

> **量级警告**：真实比荷（质子 q/m ≈ 9.6e7 C/kg）下回旋周期约 1e-7 s，1/240 步长连一个周期都采不到，
> 任何显式积分都会炸。所以磁场场景必须用**教学比荷**（q/m ≈ 1 C/kg，半径米级、周期秒级），
> 并在 UI 上把「比荷」当模型假设写出来，而不是假装是真实粒子。

## 4. 曲面轨道不能用碰撞链（这条改了架构）

做「半圆槽 / 圆轨道」时最先想到的是：用 Chain 画圆弧，让球在上面滚。实测**球在曲面上持续损失机械能**，
而且损失与步长无关、只与分段数有关：

| 分段（半圆） | 每段圆心角 | 2 s 机械能损失 |
|---|---:|---:|
| 20 | 9° | 31.2% |
| 40 | 4.5° | 19.1% |
| 60 | 3° | 13.5% |

把步长从 1/240 降到 1/960、迭代数从 8/3 加到 20/10，损失几乎不变。原因是几何性的：球每跨过一条弦，
法向速度方向被投影一次，能量逐段漏掉。细化到 1° 仍有 ~2–3%。

**改用理想约束**：`track` 用 `DistanceJoint` 把球心锁在半径 `R − r` 的圆上，每步读关节反力，
反力需要「拉」球时（法向力 < 0）销毁关节 = 脱离。

| 配置 | 临界 v₀ | 与 √(5gR)=5.1677 偏差 |
|---|---:|---:|
| 1/240，无子步 | 5.309 | +2.73% |
| 1/480，无子步 | 5.229 | +1.18% |
| 1/960，无子步 | 5.190 | +0.43% |
| **场景实际（1/960 × 2 substeps）** | **≈5.18** | **+0.24%** |

代价：轨道体不再生成弧的碰撞 fixture（只留底座/支柱），球的约束由关节负责；脱离后用 8 mm 的
「再接触」滞回，避免贴着轨道抖动导致判据永远不触发。

这里的「通过」不是「所有题都能自动生成」，而是：**不允许悄悄套一个错误的预置**。

### 第 1 题的数字

题干：一长度 l=1.0 m 的均匀薄板静止在光滑平台上，右端与平台边缘 O 对齐。小物块从薄板左端以某一初速度
向右滑动；薄板运动 Δl=l/6 时物块从右端水平飞出；物块落地时薄板中心恰好到 O。物块与薄板质量相等，
μ=0.3，g=10 m/s²。

官方答案：**v0 = 4 m/s，t = 1/3 s，h = 5/9 m**。

| 量 | 官方 | 仿真 |
|---|---|---|
| 物块离开薄板时间 | 0.333 s | **0.331 s** |
| 物块离开时速度 | 3 m/s | **3.03 m/s** |
| 薄板离开时速度 | 1 m/s | **0.974 m/s** |
| 物块落地时薄板中心位置 | 0 | **≈0.02 m** |

这四个量就是 `tests/gaokao.test.ts` 里的断言（容差覆盖离散步长）。

## 6. 明确建不了的（当前边界）

这些不是报错，是**产品边界**：题目可以手动建模，自动生成会明确拒绝并给手动入口。

- 电场 / 磁场 / 带电粒子 / 电磁感应
- 热学、光学、振动与波
- 碰撞 / 多次碰撞、传送带
- 连接体 / 滑轮 / 绳平衡
- 多过程组合（斜面 → 水平 → 圆轨道/圆弧 → 平抛）

**注意区分「自动生成不了」和「软件做不了」**：上面大部分已经能手动搭——点电荷/库仑、N 体引力、
碰撞、气缸、滑轮、多过程链都有示例或组件，只是规则解析不直接产出。
