# 产品定位复核：从「题目 → 建模」到「课件」？

> 触发：用户提出「课堂即时建模流程太长，应该改为备课时做课件，建模只是课件的一部分」。
> 结论：**流程批评成立，但「做课件」作为产品定位不成立**——不是难，是那个位置已经有人站了十年。
> 真正的需求藏在批评背后：**老师只愿意为「可复用的东西」花备课时间**。

---

## 0. 一句话结论

**你说的「时间点错了」是对的；但「所以做课件」跳得太远。**

因为「课件里插一页能动的物理模型」这件事，**希沃白板 + NB 实验室已经做了十年**，而且希沃预装在全国 44.5% 的交互智能平板上、有 700 万活跃教师、15 亿份课件。

真正要改的不是「做什么」，是**「产出物的复用单位」**：从「一道题的模型」改成「一个可复用的讲法」。

---

## 1. 你说对的部分（这一条我完全同意）

### 1.1 课堂即时建模的流程成本是真实的

你描述的流程：**拍照 → 登录微信 → 打开小程序 → 等识别 → 调参数**。

课堂 40 分钟，这套流程哪怕只花 90 秒，也是**在几十个学生面前沉默 90 秒**。老师不会冒这个风险——所以要么课前做好，要么干脆不用。

这不是体验问题，是**场景不匹配**：一个需要 5 步操作的工具，被放在一个要求「零准备、即时响应」的场景里。

### 1.2 备课与上课是两个不同的工作，工具也不同

按教育部教师工作量参照标准，**高中物理教师每周 12 课时**（多份转载口径一致）。这意味着：
- 一周约 12 次课，实际备 3–4 个不同的课（同年级多班复用同一份准备）
- **备课是「批量」的，上课是「实时」的**
- 备课在办公桌前（键鼠、大屏、能存文件），上课在教室里（触屏、全屏、不能出错）

**你之前纠结的「小程序还是 Web」，答案其实在这里：备课必须 Web，课堂也应该是 Web（全屏），小程序不属于这两个环节。**

## 3. 所以「做课件」的真正问题不是难度，是位置

把四种可能的形态摆出来，看各自站在哪：

| 形态 | 你做什么 | 竞争位置 | 判断 |
|---|---|---|---|
| **A 课件平台** | 编辑器 + 云课件 + 课堂播放 | **正面撞希沃**：硬件预装、700 万用户、15 亿课件、内置 300+ 仿真 | ❌ 不成立 |
| **B 嵌入希沃/PPT 的一页** | 只做「能动的模型页」 | **NB 实验室已接入**（一键插入，2014 年起）。⚠️ 2026-10-24 修正：这不是「位置被占」，是「**需要合作才能进**」——希沃有官方开放平台（学科工具扩展 + 课件内容元素扩展），但插件由希沃生成、需线下谈、需企业主体。详见 `INTEGRATION-WITH-TEACHING-SOFTWARE.md` | ⚠️ 门槛是商务不是技术 |
| **C 独立的一节课播放器** | 老师用你的工具上课 | 老师要在希沃/PPT 之外再切一个工具 | ⚠️ 增加摩擦，不是减少 |
| **D 微信里的一节课** | 一个链接/小程序，学生也能打开 | **希沃的盲区**：它的课件出不了教室、学生回家打不开、发不了微信群 | ✅ 有空间，但价值在课后 |

**注意 D 的悖论**：微信分发是希沃进不去的地方，但「学生课后看」的价值是**复习**，而老师备课的动力是**讲课**。如果产品只服务课后，老师就没有理由在备课时投入。

**所以单靠 D 也撑不起一个「老师会用」的产品。**

## 4. 但你的批评指向一个更根本的问题

把批评往下挖一层：

> 老师为什么不愿意在课堂上现做模型？——因为要花时间。
> 老师为什么愿意在备课时做？——**因为备课做的东西可以反复用。**

**「可复用」才是备课行为的真正动机。**

而现在的「题目 → 建模」，产出的是**一道题的模型**：
- 这道题讲完，模型就没用了
- 下一道题要重做
- 下届学生来了，题目换了，还是要重做

**这才是「太单薄」的真正原因**——不是功能少，是**产出的东西不耐用**。

所以真正要改的不是「做什么容器」，是「**让产出物可复用**」。

## 5. 建议的复用单位：「讲法」

不用「课件」，也不再用「一道题的模型」，用中间那个粒度：

### 一个「讲法」是什么

```
模型：物块在斜面上（复用现有 incline 组件）
参数步进：μ = 0 → 0.3 → 0.6 → 0.8
每步一句话：μ 到 0.6 时它不再下滑，因为 tanθ < μ
判据：是否滑动（复用现有 criterion）
```

**它是一节课的一个片段，不是一整节课；但它可以存、可以改、可以复用。**

### 为什么是这个粒度——真题数据支持

上一轮 4462 道真题的分类里有两个数字：

| 数据 | 含义 |
|---|---|
| **计算题 46% 含「临界」**（恰好/至少/刚要/取值范围） | 这类题的真实讲法就是**「同一个模型，改一个参数，看现象在哪翻转」** |
| **计算题 37% 含「多过程」** | 这类题的真实讲法就是**「同一串过程，按顺序演一遍」** |

**换句话说：老师讲临界题，本来就不是讲「一道题」，是讲「一条参数线」。**

这正是你产品已有的能力（`找临界` 是二分搜索，`params` + `layout` 支持改参数重跑），只是现在**没有被组织成「可复用的东西」**。

### 与「课件」的区别（这是关键）

| | 课件 | 讲法 |
|---|---|---|
| 内容 | 知识页 + 例题 + 练习 + 模型 | **只有模型 + 参数步进 + 每步一句话** |
| 排版 | 需要文字/公式/图片编辑 | **不需要**（那句话就是纯文本，一行） |
| 时长 | 40 分钟 | 3–8 分钟 |
| 竞争 | 希沃、学科网、AI PPT | **几乎无**（NB 是实验台，不是「参数线」） |
| 一个人能做吗 | 不能（编辑器+内容+渲染+播放器） | 能（现有 Scene + 编排层） |

## 6. 具体形态（最小可行）

### 三个时刻，一套数据

```
备课（Web，键鼠大屏）
  选一个变式 → 改参数 → 写每步一句话 → 存成「讲法」
       ↓ 得到一个短链接（Scene JSON 已经能压到 100–250 字符）
课堂（Web 全屏，F11）
  打开链接 → 按步播放 → 每步定格、标注、讲解
       ↓ 同一个链接
课后（小程序 / 微信卡片）
  学生打开同一个链接，自己拨参数、自己看
```

**这套东西的关键在于：三个时刻共用同一份数据，不需要导出、不需要转换、不需要重复劳动。**

### 小程序的角色要改

你之前的判断是「先做小程序，先上线」。按这个形态，**小程序不再是备课端，也不再是课堂端**，而是：

> **分发端**——老师把「讲法」发到班级群，学生用小程序打开。

这样反而更合理：
- 小程序不需要承担「编辑」（Canvas 上做编辑器本来就痛苦）
- 小程序擅长的是「打开即用、可转发、轻」
- 而你的 Scene JSON 分享串已经压到 100–250 字符，天然适合塞进小程序卡片

**这不是推翻「先做小程序」，是把它的职责从「主力」改成「出口」。**

## 7. 必须砍掉的（否则一定会失控）

| 砍掉 | 理由 |
|---|---|
| **知识讲解页**（文字 + 公式 + 图片排版） | 这是 PPT / 希沃的地盘，而且需要内容（不是工具能力） |
| **公式编辑器** | 同上。你的模型里已经有物理量，不需要再排版公式 |
| **题库 / 作业 / 学情** | 另一个产品，且撞学科网、智学网 |
| **通用课件导入导出（pptx 等）** | 上一轮评估里我提过 PPTX 导出，那是「嵌入别人的容器」思路，现在这条路线已被 NB 占住，降级为可选 |

**判断标准**：凡是「不需要物理引擎也能做」的功能，都不做。

## 8. 需要你决定的三件事

这三个决定会改变后面所有工作，我不替你定：

### 决定 1：接受「不做完整课件」吗？

- **接受** → 走「讲法」路线，一个人能做完，差异化清楚
- **不接受** → 那就必须面对希沃。可行的唯一路径是「只做希沃做不了的部分」（微信分发 + 课后），但这样老师备课的动力不足

### 决定 2：「一节课」要不要作为容器？

我倾向 **要，但只做最薄的一层**：允许把 3–5 个「讲法」串成一节课，加一个标题和几句过渡语。**不做知识页排版。**

这样老师仍然是「按课组织」（符合他的心智），但成本只有「讲法」的 1.2 倍，不是 5 倍。

### 决定 3：小程序退到分发端，可以吗？

如果不能接受，那就要回答一个问题：**在小程序上做编辑器，你打算怎么解决 Canvas 上排版文字和输入公式？** 这个问题目前没有好答案。

## 9. 一个我拿不准的地方

**我不确定老师是否真的会「复用讲法」。**

支持它的证据：46% 临界题结构相同、教师每年教同一批内容、备课时间有限必须复用。
反对它的证据：**老师复用的通常是「成品课件」（学科网买的、同事传的），而不是「自己搭的模型」**——因为课件可以直接改文字，模型要理解结构才能改。

如果你的目标用户是「愿意自己搭模型的老师」，那这个人群可能很小（这也解释了为什么 NB 做的是「实验台 + 300 个模板」而不是「让你搭」）。

**这一点我无法从公开数据判断，只能靠你去找 3–5 个物理老师问一句话：**

> 「你上一次讲临界问题，是怎么讲的？会想把它存下来下次用吗？」

如果他们说「存下来干什么，每年题都不一样」，那「讲法」这个假设就不成立，得回到「模板」思路。
