# 高考物理真题（2006–2026）收集与分类

> 目的：为「模型开关」的**核心服务提供问题**定边界——不是优化体验，是搞清「到底要给哪些题建模」。
> 数据：**304 份试卷、4462 道题、21 年**（2006–2026），全部来自公开 PDF 提取，非人工录入。
> 产出文件（在 `D://OneAgent//gaokao-research//` 下）：`output/gaokao-physics-2006-2026.csv`（题目级）、`output/papers.csv`（试卷级）、`data_questions.json`

---

## 0. 一句话结论

**建模服务的主战场是 1011 道计算题，不是 2627 道选择题。**

选择题占 58%，但其中只有 **8%** 需要动力学建模——其余是概念辨析、图像判读、史实、仪器读数。而计算题里 **77.6%** 需要建模。

这解释了「18 个示例覆盖不了真题」的真正原因：**示例是按知识点铺的，而知识点主要考在选择里；需要建模的题集中在计算题，且几乎每道都是多过程或多物体。**

## 1. 问题拆解（先拆，再谈方案）

你给的三个约束：**用户是老师和学生 / 服务是形象生动可交互的物理建模 / 形态轻量高效**。

把「提供服务」拆开，它其实是三个串联的子问题：

| 层 | 子问题 | 失败表现 | 现状 |
|---|---|---|---|
| **L1 识别** | 题目文字 → 建模要素（物体、过程、场、约束、判据） | 认错类型，给出一个看似合理但错的模型 | `parseProblem` 规则 v0，8 类原型 |
| **L2 构建** | 建模要素 → 可运行 Scene | 建不出来，或建出来的跑不对 | 组件库有 5 个组件 + 18 示例 |
| **L3 验证** | Scene → 结论（判据/临界/守恒） | 跑出来的数和标准答案对不上 | 判据 6 类 + 找临界，已验收 |

**关键判断：L1 的天花板由 L2 决定。** 因为「识别」不是分类问题，是**映射问题**——你只能识别出你能建的东西。所以真题分类的价值不在于「统计知识点占比」，而在于回答：

> **L2 的组件集合应该长什么样，才能让 L1 的识别率上去？**

这就是下面分类体系的轴心。分类不是为了「归类」，是为了**反推组件清单**。

### 2.2 解析质量（必须先说清）

| 环节 | 结果 | 说明 |
|---|---|---|

| 切题失败 | 6 卷题量 < 9 | 占 2%，主要是早期版式异常卷 |

**分类准确率（我自己抽样人工核对 84 道，两轮）**：

| 维度 | 准确率 | 主要错误 |
|---|---|---|
| 题型 | **≈88%** | 图-选项选择题被漏判；个别实验题落在选择题段 |
| 知识模块 | **≈95%** | 「双缝干涉」曾判成振动与波；带电体在重力场中，力学/电磁边界模糊 |

**这意味着：下面的百分比有 ±5–12% 的误差带。用来定优先级足够，用来做精确断言不够。**

### 2.3 一个必须交代的局限

**约束识别偏弱。** 计算题里有 19.6% 被判为「无约束」，其中一部分其实是漏识别（比如只写「在竖直平面内」）。所以第 4.3 节的约束占比是**下限**，真实值更高。

## 3. 分类体系（四轴）

不是按知识点分，是按**建模需要什么**分。

### 轴 A：题型（结构层）

`选择-单选` / `选择-多选` / `填空` / `实验` / `计算` / `选修`

### 轴 B：知识模块

`力学` / `电磁学` / `热学` / `振动与波` / `光学` / `近代物理`

### 轴 C：建模要素（**产品层，最关键**）

| 要素 | 取值 | 决定什么 |
|---|---|---|
| **场** | 无场 / 电场 / 磁场 / 复合场 | 要不要写场力求解器 |
| **约束** | 水平面 / 斜面 / 圆·弧轨道 / 板·车 / 绳 / 杆 / 弹簧 / 传送带 | 组件库要哪些 |
| **过程数** | 单过程 / 多过程串联 | 要不要「过程链」机制 |
| **临界** | 有 / 无（恰好、至少、刚要、取值范围） | 「找临界」是不是核心交互 |
| **物体数** | 1 / 2 / 3+ | 要不要多体与碰撞 |

### 轴 D：可建模性（**决策层**）

| 级别 | 含义 | 对应能力 |
|---|---|---|
| **D0** | 不可建模 | 概念辨析、物理学史、单位量纲、纯图像判读、仪器读数、近代物理定性 |
| **D1** | 可静态建模 | 受力分析图、场线、光路、过程示意——画出来就行，不需要仿真 |
| **D2** | **可动力学建模** | 有过程、有数值、要求解——**这才是「模型开关」的目标** |
| **D3** | 需专门模块 | 电路计算、热力学过程、波形/振动图像 |

## 4. 分布结果

### 4.1 题型（4462 道）

| 题型 | 数量 | 占比 |
|---|---:|---:|
| 选择-单选 | 2591 | 58% |
| **计算** | **1011** | **23%** |
| 实验 | 489 | 11% |
| 其他（无法归类，多为图-选项题） | 203 | 5% |
| 填空 | 79 | 2% |
| 选修 | 53 | 1% |
| 选择-多选 | 36 | 1% |

### 4.2 可建模性（4462 道）—— 最重要的表

| 级别 | 数量 | 占比 |
|---|---:|---:|
| D1 可静态建模 | 1511 | 34% |
| **D2 可动力学建模** | **1139** | **26%** |
| D0 不可建模 | 1118 | 25% |
| D3 需专门模块 | 694 | 16% |

**但按题型拆开，结论完全不同：**

| | 选择题（2627 道） | 计算题（1011 道） |
|---|---:|---:|
| D2 可动力学建模 | **221（8%）** | **785（78%）** |
| D1 可静态建模 | 1255（48%） | — |
| D0 不可建模 | 754（29%） | 55（5%） |
| D3 需专门模块 | 397（15%） | 164（16%） |

**读法**：选择题是「判断对错」，不需要跑起来；计算题是「求出来」，必须跑起来。**这两件事对应两种产品，不能混着做。**

### 4.3 计算题的建模要素（1011 道，这是产品的主战场）

**场分布**

| 场 | 占比 |
|---|---:|
| 无场（纯力学） | 61% |
| 磁场 | 21% |
| 复合场（E+B） | 11% |
| 电场 | 7% |

→ **纯力学六成，但场类合计 39%。** 你现在明确拒绝电磁，等于主动放弃四成计算题。

**约束出现频次**（可多选，分母 1011）

| 约束 | 频次 | 占比 |
|---|---:|---:|
| 水平面 | 275 | 27% |
| **圆/弧轨道** | **151** | **15%** |
| 绳 | 102 | 10% |
| 斜面 | 97 | 10% |
| 杆 | 87 | 9% |
| 板/车 | 70 | 7% |
| 弹簧 | 68 | 7% |
| **传送带** | **17** | **1.7%** |

**结构与判据**

| | 占比 |
|---|---:|
| 含**临界**（恰好/至少/刚要/取值范围） | **46%** |
| 含**多过程**（然后/进入/滑上/之后…） | **37%** |

**组合复杂度**：计算题的「场 × 约束组合 × 多过程」共有 **161 种**不同组合。前 15 种覆盖 **62%**，前 30 种覆盖 **76%**。

→ **这直接说明：逐题做预置是死路（161 种），但只做 8 个原型也是死路（覆盖不到三成）。正确解法是「组件 × 可串联」，而不是「原型枚举」。**

### 4.4 年代趋势（计算题）

| 年代 | n | 力学 | 电磁 | 临界 | 多过程 | 有场 |
|---|---:|---:|---:|---:|---:|---:|
| 2006–2010 | 208 | 62% | 25% | 44% | 38% | 38% |
| 2011–2015 | 198 | 56% | 33% | 44% | 32% | 42% |
| 2016–2020 | 170 | 49% | 38% | 47% | 42% | 42% |
| 2021–2026 | 435 | 49% | 30% | **48%** | 37% | 36% |

**两个趋势值得注意**：
1. **临界题占比在缓慢上升**（44% → 48%），且 2021 年后计算题数量翻倍（435 道）——新课标卷增多，计算题权重上升。
2. 力学占比从 62% 降到 49%，**电磁+复合场合计稳定在 36–42%**。换句话说，「只做力学」的天花板在长期看是在**下降**的。

## 5. 三个推翻既有判断的发现

### 5.1 传送带只有 0.6%——上一轮我建议错了

上一轮看完 `physics-lab-suite` 竞品后，我写「传送带值得做，因为竞品有、且你的 `prismatic` 已具备」。

**数据不支持这个判断。** 全量 4462 道题里含传送带的只有 **26 道（0.6%）**，计算题里 17 道（1.7%）。

竞品做传送带，可能是因为它按「实验/演示」组织内容，不是因为传送带是高频考点。**按题量算，传送带的优先级应该排在绳（10%）、斜面（10%）、杆（9%）、板（7%）、弹簧（7%）之后。**

这是我上一轮的判断失误，用竞品功能当需求证据是不可靠的。

### 5.2 选择题不是主战场，但它可能是「老师更想要的」

选择题占 58%，其中 D1（可静态建模）占 48%。

D1 的含义是：**不需要仿真，只需要「画对一张图」**——受力分析图、场线、运动过程示意、v-t 图。

这对产品形态是个重要提示：
- **D2 是「跑起来看结果」，适合课堂演示，但需要完整物理引擎**
- **D1 是「把图讲清楚」，是老师板书的主要内容，但不需要引擎**

而且 D1 题量是 D2 的 1.3 倍（1511 vs 1139）。

**这不意味着要转向做画图工具**（那会丢掉你的核心资产）。但它意味着：**同一个场景，除了「播放」，还应该能「定格 + 标注 + 逐步揭示」**——这恰好是上一轮从 OpenMAIC 借来的 `reveal` 与「讲解脚本」要解决的问题。

### 5.3 覆盖率 11% 的真正原因：不是原型少，是「结构复杂度」没被建模

先算一个理论上限：计算题中「力学 + 无场 + 约束命中现有组件（斜面/圆轨道/板/水平面/弹簧/绳/杆）」的有 **295 道 = 计算题的 29%**。

而 `docs/GAOKAO.md` 实测是 **1/9 = 11%**。

**29% 到 11% 的差距在哪？**

| 原因 | 数据 |
|---|---|
| 多过程（37% 的计算题） | 现有原型全是单过程，斜面+圆弧是唯一例外 |
| 双体/多体（板块、连接体） | 现有只有「板块+平抛」一个双体原型 |
| 约束组合（斜面→水平→圆弧串联） | 现有 `arcChain` 用 13 段折线近似 |

**所以你说得对：这不是定位问题，是设计问题。** 但设计问题的具体形态不是「原型不够多」，而是：

> **原型是「一道题一个形状」，而真题是「几个组件按顺序串起来」。**

161 种组合、前 30 种覆盖 76% —— 这个分布形状说明：**组合是长尾的，但基元是有限的。** 正确解法是把「原型」降级为「基元 + 串联规则」，而不是继续加原型。

## 6. 对「核心服务提供」的推论

### 6.1 服务的最小单元应该是什么

现在的最小单元是「一个预置场景」。按数据看，应该改成：

```
基元（组件 + 约束 + 判据）  ×  串联（过程链）  ×  参数（题目给的数值）
```

因为：
- 基元有限（约束只有 8 类，场只有 4 类）
- 组合长尾（161 种）
- **只有「基元 × 串联」能同时覆盖长尾和保持可编辑**

### 6.2 组件优先级（按计算题题量，不是按我的直觉）

| 优先级 | 能力 | 依据 | 现状 |
|---|---|---|---|
| **P0** | **多过程串联**（任意 2–4 段组合，精确圆弧） | 37% 计算题含多过程；161 种组合 | 只有 `arcChain` 一条，且是折线近似 |
| **P0** | **双体/多体通用**（不限「板块+平抛」） | 板块 7%、绳 10%、杆 9% 都涉及多体 | 只有 1 个双体原型 |
| **P0** | **临界判据的通用化**（不是每个场景写一个 `search`） | **46% 计算题含临界** | 有 `search`，但绑定单参数路径 |
| **P1** | **匀强电场中的带电粒子**（含类平抛、加速、偏转） | 电场 7% + 复合场 11% = 18% | 有 `efield` 示例，但解析器明确拒绝 |
| **P1** | **磁场中的圆周运动 + 边界** | 磁场 21%（计算题第二大场） | 有 `crossedFields`，但边界/区域处理弱 |
| **P2** | 传送带 | 1.7%（低于我的上一轮判断） | 无 |
| **不做** | 电路计算、热力学过程、波形图 | 合计 D3 16% | 明确拒绝是对的 |
| **不做** | 近代物理、光学定性 | D0 为主 | 明确拒绝是对的 |

### 6.3 一个反直觉的推论

**「临界」比「电磁」更值得优先做。**

- 临界：46% 的计算题，且**跨模块**（力学临界、电磁临界都有）
- 电磁：39% 的计算题，但需要新求解器（场力、边界、区域门控）

临界是**已有能力的横向扩展**（判据通用化 + 参数扫描），电磁是**纵向新建**（新物理）。

如果只能做一个，做临界。因为临界的投入产出比更高，而且它是你产品定位里「改一个条件看结果怎么变」的最直接体现。

## 7. 数据局限（必须写在结论旁边）

1. **分类准确率 ≈88–95%，不是 100%。** 所有百分比有误差带，方向可信，绝对值不可当精确值用。
2. **约束识别偏弱**：19.6% 的计算题被判「无约束」，部分是漏识别。所以约束占比是下限。
3. **2 份扫描件未纳入**，6 份卷切题失败。占 2%。
4. **「物体数」字段不可靠**：靠关键词（两球/甲、乙/A、B）推断，双体识别可能偏低。
5. **许可限制**：语料是 CC BY-NC 4.0。**免费可用，商业化不可用。** 如果将来接广告，这份语料需要换成自行采集或授权的来源。
6. **未做「标准答案对照」**：本报告只做题型/要素分类，没有验证「每道题的答案是否与建模结果一致」。这是下一步该做的事（见第 8 节）。
