# 画布：画什么就是什么

> 这一篇讲**画布上的一切表达**：怎么画出一个物体、画出来的东西长什么样、场怎么建、批注怎么画。
>
> 一句话原则：**不发明符号，用教材里已有的。** 老师认识剖面线、认识 `××`、认识「轻」绳。
> 所以这里没有调色板、没有图层、没有形状按钮——只有「把题画出来」这一件事。

---

## 1. 为什么删按钮

| | 按钮式（旧） | 画图式（现在） |
|---|---|---|
| 用户要想 | 「这是滑块还是小球？该点哪个组件？」 | 「题里长什么样，我就画成什么样」 |
| 斜面上的方块 | 选矩形 → 拖 → 再改分类 | 画个方块 → 自动是矩形地形 |
| 小球 | 选圆 → 拖 → 自动是球 | 画个圈 → 自动规整成圆，且是球 |
| 电场 | 世界面板里「加匀强电场」→ 再调 E | 点「电场」，拖一块区域 |

**按钮强迫用户先理解抽象概念，画图只要求他把题画出来。**

## 2. 笔：一笔一个形状

左栏第 2 个是笔（`tool = 'pen'`）。松手时跑一次识别（`packages/core/src/recognize.ts`）：

| 画出来的样子 | 判据 | 变成 |
|---|---|---|
| 闭合 + 径向偏差 < 12% | 到包围盒中心的距离标准差 / 均值 | **圆**（半径取均值）→ 球（`particle`，会动） |
| 闭合 + 面积 / 包围盒面积 > 0.82 | 矩形填充率 ≈1，三角形 ≈0.5 | **轴对齐矩形** → 地形（`static`） |
| 闭合但都不像 | 其余 | **多边形** → 地形 |
| 开放 + 最大偏离 / 弦长 < 5% | 够直 | **直线** → 细线地形 |
| 开放 + 有弯 | 其余 | **折线** → 细线地形 |
| 太小（包围盒 < 0.12） | — | 不产生任何东西（只是点了一下） |

三条实现上的坑（都踩过）：

1. **圆形度必须用原始采样点**。RDP 简化后矩形只剩 4 个角，到中心距离全都一样，会被判成圆。
2. **圆用包围盒中心，不用质心**。简化后采样疏密不均，质心会偏 0.07。
3. **不认旋转矩形**。画歪的方块会被规整成轴对齐矩形——题里几乎不需要斜放的方块；真要斜的，双击切成「物体」再转。

识别完 toast 会说「识别为圆 / 矩形 / …」，认错了 `Ctrl+Z` 重画。

## 3. 画完之后的物理性质

画出来的是**普通 body**，不是特例：

| 画出来的 | 默认 | 物理含义 | 怎么改 |
|---|---|---|---|
| 圆 | `particle` + `role: 'object'` | 会动、会滚、会落 | 检查器改半径 / 质量 / 电荷 q / 初速度 |
| 方块、三角、多边形 | `static` + `role: 'terrain'` | 固定地形，能挡能托 | 检查器改摩擦 μ |
| 直线、折线 | `static` + 细线 | 轨道 / 地面 / 挡板 | 同上 |

- **「光滑」不是组件，是一个数**：μ 拖到 0 就是光滑，μ > 0 就是粗糙（表面挂短斜纹）。
- **双击**在 地形 → 物体 → 轨道 之间循环：方块想当滑块，双击两次。
- 画在斜面附近的球会自动吸附上去（`snapBodyNow`）。

## 4. 电场 / 磁场：两个按钮，拖一块区域

左栏两个独立按钮：**电场**、**磁场**。用法一样——**按住拖出一个矩形，场就长在这块区域里**（像选框，不是画箭头）。

| 操作 | 结果 |
|---|---|
| 拖出一个矩形 | 建一块区域 + 一块场，场只作用在虚线框里 |
| 点一下（拖得太小） | 建一块**全场**的场 |
| 建完 | 自动选中，左侧面板立刻能调 |
| 再点这块场区 | 重新选中（虚线框变紫） |
| Esc / 点空白 | 取消选中 |

**左侧面板（选中场时）**：电场 = 场强 E（0–120 N/C）+ 方向（0–360°，0° 向右、90° 向上）；
磁场 = 磁感应强度 B（0–6）+ 方向（向外 · / 向里 ×）；两者都有「删除这块场」（连区域一起删）。

**为什么方向不做成手势**：试过「画箭头 = 电场、点 = 向外、画 × = 向里」的一支场笔，三个手势都要靠猜，
画歪一点就判错。现在是「拖区域（几何）+ 滑杆（方向）」两件正交的事，各自都不需要猜。

> 场只作用于**带电体**（`q ≠ 0`），所以画完场要去检查器给球设一个 q——toast 会提醒这句。

## 5. 外观即语义（视觉语法）

**开关是「让用户操作概念」，外观是「让用户看见事实」。**

不做「固定/可移动」的两态开关，而是让画面直接说明——这条比我最初提的面板开关好，理由是：
用户不用先知道「有这个概念」，上课时也不用点开面板才能确认。

| 物理条件 | 视觉编码 | 教材依据 |
|---|---|---|
| **固定** | 轮廓外侧 **45° 剖面线**（间距 7px、1px、22% 墨） | 力学固定端标准符号 |
| **光滑** | 表面线干净 | 光滑面不画纹理 |
| **粗糙** | 表面线外侧挂短斜纹 | 教材粗糙面画斜线 |
| **带电** | 体心 11px 圆 + 十字/横杠，红正蓝负 | 教材电荷符号 |
| **磁场向里** | 区域内 **`×` 阵列**（32px 间距） | 教材标准符号 |
| **磁场向外** | 区域内 **`·` 阵列** | 教材标准符号 |
| **电场** | 区域内短箭头阵列（104px 间距） | 教材场线方向 |
| **有界场** | 虚线边界 + 只在场内画符号 + 角落 `E`/`B` 标签 | 「磁场仅分布于…」 |
| **轻绳 / 轻杆** | 细线 1.2px，不标质量 | 「轻」= 不计质量 |

三条实现规则：

1. **符号画在接触面外侧**，不侵入物体填充——填充是识别色，侵入会降低可辨识度。
2. **可叠加，不互斥**。一个斜面可以同时「固定 + 粗糙」，所以剖面线和粗糙纹是两个独立通道，
   不要做成「一个枚举选一种外观」（组合会爆炸）。
3. **不抢注意力**。剖面线 22% 墨、场符号 20–26% 蓝；`accent`（紫）只留给**选中态和力箭头**；
   装饰线宽 ≤ 1.2px，不参与选中高亮。

**下限**：屏幕上的物体短边 < 24px 时，一律不画装饰（`DECO_MIN_SIDE`）。宁可没有，不要脏。

> **外观有边界**：**静态条件靠外观，过程条件靠判据**。
> 「恰好不下滑」是过程条件，外观表达不了，只能靠播放后判据翻转。两者别混。

**还没做的**：粗糙面短斜纹、可移动的 1.5px 缝隙、选中时的角色徽标。

## 6. 批注：指出情境里的某处

批注是「指着某处说」，不是「把课讲一遍」。这条边界是从产品原则推出来的（只提供情境，不提供怎么讲）：

| ✅ 是批注 | ❌ 不是批注 |
|---|---|
| 箭头指向某个物体 | 板书推导过程 |
| 圈住某个区域 | 分步骤讲解 |
| 旁边写一个数值 | 画完整的解题流程图 |

**只做 L2 临时墨迹**（自由笔迹，讲完就擦），不做 L1 结构化批注（箭头/文字/圈 + 序列化）——
因为带批注的场景会撑爆 `p1.` 分享串（一个结构化标注约 60 字符，5 个就把 8 个场景的预算砍到 2 个）。

四个必须守住的约定：

1. **点存世界坐标，线宽存屏幕像素**。点存屏幕坐标的话，老师缩放一下笔迹就错位——这是最常见的实现错误。
2. **墨迹画在最上层，但不参与选中**。不参与命中测试（不会挡住物体拖拽），但可被橡皮擦擦掉。
3. **批注箭头必须和力箭头区分开**：力箭头是引擎画的、有数值、会跟着物体动；批注是墨色虚线、没数值、固定在画布上。
4. **工具名不能叫 `pen`**（那个是建地形的），叫 `ink`。否则两个语义会互相污染——老师在「手绘」里画一条线，
   结果多了一块地形，这是现在就可能发生的困惑。

不做：颜色选择、粗细调节、图层、荧光笔、导出图片、笔迹识别成文字。那些是白板的地盘
（见 [RESEARCH.md](RESEARCH.md) §5：希沃已经占住了那个位置）。

## 7. 手动调整大小

选中任何东西，包围盒右下角有个小方块手柄：拖它按比例缩放（圆改半径、矩形改宽高、折线/多边形缩放顶点）。
范围 0.2×–5×，松手后重建仿真。检查器里也有精确滑杆——手柄负责「手感」，滑杆负责「数值」。

## 8. 已知边界

- **没有预置组件库**。气缸、滑轮这类「多体 + 约束」的组合不能一键插入；要搭就是画两个球 → 连接工具连绳，
  然后「＋ 存为组件」存下来（见 [COMPONENTS.md](COMPONENTS.md)）。
- **识别不是万能的**：手抖太厉害会判成折线；认错了靠撤销重画，不做「猜你想画什么」的二次确认弹窗（会打断课堂节奏）。
- **场没有强度手势**：拖出来的场默认 E=40、B=2，强度在左侧面板调。用「拖多大就多强」看着聪明，实际很难画准。
- **全场场不可点选**：没有区域的场要改，用「世界」面板里的 E/B 滑杆。
- **批注在小程序端没做真机验证**：触摸采样率、丢点都还没测。

```bash
node scripts/shots-ink.mjs                  # 9 项：批注（世界坐标 / 缩放保留 / 清空 / 橡皮 / 换场景清空）

```
