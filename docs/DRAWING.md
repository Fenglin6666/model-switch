# 画图：画什么，什么就是组件

> 2026-10-25（v5.7）。这一版把「组件库」删了——没有「+ 点电荷 / 天体 / 气缸 / 滑轮」这些按钮，也没有「矩形 / 圆 / 三角」这些形状按钮。
> 左栏只剩**笔**和**场笔**：用户在画布上画什么，系统就把它变成什么，并且带上真实物理性质。

---

## 1. 为什么删按钮

| | 按钮式（旧） | 画图式（现在） |
|---|---|---|
| 用户要想 | 「这是滑块还是小球？该点哪个组件？」 | 「题里长什么样，我就画成什么样」 |
| 斜面上的方块 | 选矩形 → 拖 → 再改分类 | 画个方块 → 自动是矩形地形 |
| 小球 | 选圆 → 拖 → 自动是球 | 画个圈 → 自动规整成圆，且是球 |
| 电场 | 世界面板里「加匀强电场」→ 再调 E | 画个箭头，再拖一块区域 |
| 磁场方向 | 面板里改 B 的正负 | 点一下 = 向外（·），画 × = 向里 |

**按钮强迫用户先理解抽象概念，画图只要求他把题画出来。**

---

## 2. 笔：一笔一个形状

左栏第 2 个是笔（`tool = 'pen'`）。松手时跑一次识别（`packages/core/src/recognize.ts`），决定这一笔是什么：

| 画出来的样子 | 判据 | 变成 |
|---|---|---|
| 闭合 + 径向偏差 < 12% | 到包围盒中心的距离标准差 / 均值 | **圆**（半径取均值）→ 球（`particle`，会动） |
| 闭合 + 面积 / 包围盒面积 > 0.82 | 矩形的填充率 ≈1，三角形 ≈0.5 | **轴对齐矩形** → 地形（`static`） |
| 闭合但都不像 | 其余 | **多边形** → 地形 |
| 开放 + 最大偏离 / 弦长 < 5% | 够直 | **直线** → 细线地形 |
| 开放 + 有弯 | 其余 | **折线** → 细线地形（保留简化后的点） |
| 太小（包围盒 < 0.12） | — | 不产生任何东西（只是点了一下） |

三条实现上的注意：

1. **圆形度必须用原始采样点**。RDP 简化后矩形只剩 4 个角，到中心距离全都一样，会被判成圆（踩过这个坑）。
2. **圆用包围盒中心，不用质心**。简化后采样疏密不均，质心会偏 0.07。
3. **不认旋转矩形**。画歪的方块会被规整成轴对齐矩形——题里几乎不需要斜放的方块；真要斜的，双击切成「物体」再转。

识别完会在 toast 里说明「识别为圆 / 矩形 / …」，认错了就 `Ctrl+Z` 重画。

## 3. 画完之后的物理性质

画出来的是**普通 body**，不是特例：

| 画出来的 | 默认 | 物理含义 | 怎么改 |
|---|---|---|---|
| 圆 | `particle` + `role: 'object'` | 会动、会滚、会落 | 检查器改半径 / 质量 / 电荷 q / 初速度 |
| 方块、三角、多边形 | `static` + `role: 'terrain'` | 固定地形，能挡能托 | 检查器改摩擦 μ（**光滑就是 μ=0**） |
| 直线、折线 | `static` + 细线 | 轨道 / 地面 / 挡板 | 同上 |

- **「光滑」不是组件，是一个数**：把摩擦 μ 拖到 0，表面线就是干净的；「粗糙」就是 μ > 0，表面挂短斜纹（视觉语法）。
- **双击**在 地形 → 物体 → 轨道 之间循环：方块想当滑块，双击两次即可。
- 画在斜面附近的球会自动吸附上去（`snapBodyNow`）。

## 4. 场笔：箭头 / 点 / ×

左栏第 3 个是场笔（`tool = 'field'`）。三种手势 + 一次「定范围」：

| 手势 | 结果 | 物理 |
|---|---|---|
| 拖一条**长线**（> 0.8） | 电场，方向沿箭头 | `Field{kind:'uniform', type:'E', vector: 单位向量 × 40}` |
| **点一下** | 磁场 ·（向外） | `Field{type:'B', bz: +2}` |
| **画一个 ×**（两笔交叉，1.4s 内） | 磁场 ×（向里） | `Field{type:'B', bz: -2}` |

**第二笔定范围**（画完第一笔会出现提示条）：

- **拖一块区域** → 生成一个 `Region{role:'field'}`，场带上 `regionId`，只作用在虚线框里（物理层 `forces.ts` / `simulation.ts` 真的按区域门控）；
- **点一下** → 全场；
- **Esc** → 取消这次场。

场只作用于**带电体**（`q ≠ 0`），所以画完场要去检查器给球设一个 q——toast 会提醒这一句，不说就是让人以为坏了。

## 5. 手动调整大小

选中任何东西，包围盒右下角有个小方块手柄：拖它按比例缩放（圆改半径、矩形改宽高、折线/多边形缩放顶点）。

- 缩放范围 0.2×–5×，松手后重建仿真；
- 检查器里也有精确滑杆（半径 / 长度 / 角度），手柄负责「手感」，滑杆负责「数值」。

---

## 6. 已知边界

- **没有组件库了**：气缸（活塞 + 气体）、滑轮（Atwood 组合）这类「多体 + 约束」的组合没法一键插入。要搭就是：画两个球 → 连接工具连绳（`rope`）。气缸目前只能从示例场景改（世界面板能调气体 T）。
- **识别不是万能的**：手抖太厉害会判成折线；认错了靠撤销重画，不做「猜你想画什么」的二次确认弹窗（会打断课堂节奏）。
- **场笔没有强度手势**：E 固定 40、B 固定 2，强度在检查器/世界面板里调。用「线的长度」映射强度看着聪明，实际很难画准。
