# 界面设计：精密工作台（v4）

> 目标来自用户：**简洁、高效、性感；实用、方便、合理。** 本文件记录方向、决策、评审和证据。

## 1. 这个产品是什么

给高中物理老师/学生用的「题目 → 建模」工具：一道题进去，一张形象、能拨动的模型出来。核心不是炫技，而是：

1. 把题目交给它（现在粘贴文字；图片识别 / 拍照后续）；
2. 得到一张能播的模型，看轨迹、受力、判据；
3. 点一个组件，改角度 / 摩擦 / 初速度 / 外力——生成不准就直接改；
4. 改一个条件再看，把“大致对”修成“这道题”。

生成不可能次次都对，所以**手动编辑不是备选项，是产品的一半**：它既是 AI 生成的兜底，也是老师/学生自己的建模台。

设备：Web（桌面为主）与微信小程序（手机）。物理图形、标签和数值必须一直清楚。

## 2. 北极星与方向

**北极星：一张安静的实验台。**

场景是主角，界面是仪器面板：纸感画布提供物理题的"纸"，炭黑框架把注意力收进场景，单一烧橙色只用来指示"正在发生"和"当前值"，衬线标题和等宽数字给产品一点编辑感和仪器感。风格不靠装饰，靠比例、留白、字重和线条。

### 设计方向卡

| | |
| --- | --- |
| 品类 | 物理题目建模 / 教学演示工具 |
| 用户 | 老师（讲解、出题）、学生（看懂条件） |
| 首屏 | 题目 → 建模：主按钮「题目 → 建模」，次按钮「从空白画布开始」；下面才是示例 |
| 主视觉 | 暖纸画布 + 炭黑顶栏/工具轨 + 烧橙信号 + 一条线稿轨迹 |
| 字体 | 标题：宋体（Songti/SimSun）；界面：苹方/雅黑；数字：SF Mono/等宽 |
| 色彩 | 纸 `#f5f2ea`、炭 `#1b1e23`、墨 `#1d2025`、橙 `#dd5735`、语义蓝/绿只给数据 |
| 形状 | 12–16 圆角、1px 发丝线、无重阴影、悬浮层才允许极轻投影 |

### 为什么不是深色场景

物理图里大量黑字标签、受力箭头和纸面网格；深色画布会牺牲可读性。把"深色"放在**框架**（顶栏、工具轨），画布保持纸色，既安静又有对比。

## 3. 结构与决策

### 场景页

- **顶栏**：炭黑、54px、14 圆角；左侧返回 + 品牌橙点 + 标题 + 标签；中间只留重置/播放；速度和图表不再挤在中间（速度统一到工具轨的 `1×`）。
- **工具轨**：炭黑、44px、分组（选择/连接/手/橡皮 → 形状 → 受力 → 速度）；当前工具用烧橙实心；形状面板是浅色浮层。
- **画布**：暖纸 + 细网格；物体颜色降饱和（滑块改成钢蓝、球用烧橙），避免和 UI 抢。
- **底部状态条**：64px，悬浮居中，最大 1000px；左边"运行中/已暂停 + 速度 + 判据"，右边三个带图标的动作：**题目 / 世界 / 找临界**。它们是动作，不是筛选标签。
- **组件检查器**：同一张悬浮卡，最大 1000px 居中；拖拽柄、标题/类型/实时数值（等宽）、删除/关闭、样式开关（实心/细线）都收进头部；正文两列，角度/摩擦、初速度/方向、质量/添加外力；模型和角色并排。删掉了原来的橙色重复说明和底部孤立样式行。
- **图表**：默认收起，右上角不再放一张空的 `v–t` 卡；需要时点顶栏图表键。
- **贴地/合并/多外力/题目解析**：沿用 v3.3 能力，只调整了呈现。

### 选择页

- **炭黑品牌区**：`MODEL SWITCH · 题目建模` 等宽小字，宋体大标题“模型开关”，一句话“把一道物理题，变成一张能拨动的模型。”；主 CTA「题目 → 建模」，次 CTA「从空白画布开始」；桌面端下一行说明入口现状（文字已支持，图片识别/拍照后续）与兜底（生成不准直接改）；右侧一条纯装饰的斜面→圆弧→抛物线线稿（不是示意图，不承担信息）。
- **4×2 预置卡（桌面）**：18 个示例按 4 列排，一屏先看 8 个；卡片是发丝线白卡，编号 01–18 用等宽数字；悬停时橙描边 + 轻投影 + ↗。示例是生成的参照，不是主路径。
- **手机**：主/次 CTA 并排，横向卡（左预览右文字），说明最多两行，编号在标题上方；首屏能看到 4–5 个场景，滚动条是 2px 细线。
- **页脚**：一屏装得下时出现“18 个示例 · 题目生成与手动编辑始终可用”。

### 题目弹层

- 等宽 eyebrow `PROBLEM → MODEL` + 宋体标题「题目 → 物理建模」，正文与按钮沿用同一套橙/发丝线；示例题目一键填入。
- 三个入口：`粘贴文字`（橙色描边、可用）、`图片识别` / `拍照`（虚线灰、disabled），下面一行“图片识别与拍照即将支持，先粘贴文字；生成不了就手动搭。”——不假装能识别。
- 底部常驻「手动搭：从空白画布开始」；生成失败时错误红字 + 这个入口变成橙色加粗，兜底路径不藏在文案里。
- 生成成功：弹层关闭，状态条出现橙色 chip「题目初稿 · 可改」。

## 4. 动效与反馈

没有加"炫"的动画，保持即时响应：

- 工具/图标/胶囊/卡片有 hover 和按下态；当前工具用橙色实心。
- 播放键播放/暂停图标切换；运行状态点变绿。
- 滑杆拖动即时重建；toast 浮层提示。
- 卡片悬停抬升；页面切换即时（不做转场，优先效率）。

## 5. 独立评审

按"存量界面润色一整页以上"的规则，做了一轮**不打分**的独立评审（评审者只看截图，不看代码/过程）。主要反馈与处理：

| 反馈 | 处理 |
| --- | --- |
| 蓝色滑块/对象比播放键抢眼 | 物体颜色降饱和（钢蓝、烧橙），UI 的橙只给主操作/当前值 |
| 滑轨太淡；初速度/方向挤；橙色说明重复 | 轨道 2→3px、对比 0.14；方向标签缩短；说明改为中性等宽一行 |
| "样式：实心"孤立 | 移到检查器头部，和删除/关闭同组 |
| 桌面检查器过疏、滑杆横跨半屏 | 检查器最大 1000px 居中；滑杆约 490px |
| 空 v–t 卡占右上 | 图表默认收起，顶栏图表键打开 |
| 状态条三颗像筛选标签 | 全部加图标（doc / orbit / search 文字），状态激活时变橙 |
| 手机 1× 和桌面位置不一致 | 速度只保留在工具轨，两端一致 |
| 手机预设卡说明被截断 / 01 缺失 / 红角标 | 说明两行；编号移到文字区左上；手机禁用 hover |
| 手机顶部图标偏挤 | 小程序隐藏分享后为 3 图标 + 播放；Web 手机仍保留分享 |
| 直接输入数值 | **未做**：当前仍是滑杆；下一轮可给滑杆值加可点击输入 |
| 检查器改侧栏 | **未做**：选择"居中控制台"而不是侧栏，避免遮挡画布 |

## 7. 已知边界

- 数值仍靠滑杆，不能直接键入；长标题在手机顶栏会省略（已优先用预置短标题）。
- 手机 Web 顶栏仍是 4 个图标 + 播放；小程序隐藏分享后更松。
- 图表默认收起，首次使用者需要发现顶栏图表键；这是"先看场景"的取舍。
- 语义色（判据绿、图表蓝）保留，不强行中性化，因为它们在传达状态/数据。
- 小程序原生状态栏在深色主题下是黑底白字，与炭黑顶栏连续；不是画布绘制。

## 8. v4.1：不做 A/B

用户明确判定 A/B 是伪需求。产品不再提供 A/B 双跑：状态条、顶栏、预置场景里的 A/B 都移除；每个场景先按题目假设定下模型。解析器把「滑块/小球、滚动/纯滚动、光滑/粗糙、固定/可移动、空气阻力」写进场景并显示假设；「找临界」保留，因为它是单场景二分搜索，不是 A/B。

## 9. v4.2：代码清理（无视觉变化）

删除了 A/B 的全部旧脚手架（`compare/sceneB/simB`、幽灵 B、A/B 图表、`renderControls` 与 `Control` 控件渲染）以及旧场景控制面板遗留的 `Scene.controls/Control/presets controls/compact v`。分享紧凑串现在只保留 `t/p/a/e`；带形状变化的解析场景靠 `params + layout` 复现，仍走 `p1.`。UI 不变。

## 10. v4.3：更安静的运动与几何

- **速度**只保留一根实线矢量箭头；删除蓝色虚线手柄/端点圆圈，选中轮廓由虚线改实线。箭头端点仍可拖。
- **贴合**不再画提示：删除拖动时的 snap hint 圆圈和状态；物体仍吸附到斜面/圆弧表面。拖动期间隐藏旋转手柄，避免额外圆圈。
- **角色/模型面板删除**：地形/物体/轨道靠双击循环；质点/刚体不再是用户选项，内部 kind 仅为物理服务。
- **几何参数**进入检查器，按相对模型尺寸：斜面/折线/多边形有角度+长度，圆弧/圆有半径，竖直圆轨道有轨道半径（并同步轨道约束/小球起点/最高点）。UI 写明「几何为相对模型尺寸，不必等于真实米数」。

## 11. v4.4：真实高考题与板块模型

- 新增第 9 个预置「板块 + 平抛」，对应 2024 新课标卷第 12 题；薄板/物块/平台/地面分开，板块摩擦、平台光滑、薄板不翻转；物块离开薄板后进入平抛。
- 板块场景使用显式取景（`world.view.fit=false`），相机聚焦板/物块/O 点，而不是把 6 m 平台和地面缩成一条线；检查器可调板长、平台高度、初速度、质量、摩擦。
- 解析器增加覆盖闸门：真实高考题里常见的电场/磁场、热学、光学、波、碰撞、传送带、连接体、追及，命中时明确返回 `unsupported`；多过程组合也不硬套单阶段预置。
- 选题页 4×2 的前 8 个不变，第 9 个在下一行；实测报告见 [GAOKAO.md](GAOKAO.md)。

## 12. v4.5：通用相互作用的界面

- 世界面板新增「库仑力」「N 体引力」两个开关；检查器在有库仑力时出现「电荷 q」滑杆。点电荷、卫星、两球碰撞作为三个通用交互示例，和斜面/圆轨道/板块并列。
- 解析器的定位明确为加速器：能自动生成的就生成，不能生成的明确拒绝，并在提示里指向通用示例/空白画布手动搭；不再为每道题加预置。（v5.2 起题目是主入口，见 §19。）
- 选择页 4×3 十二个示例；「从空白画布开始」仍是主入口；题目库/解析是次要能力。

## 13. v4.6：热学与连接体的界面

- 气缸场景：半透明气体填充 + `P/V/T` 读数；世界面板增加气体温度滑杆，升温后活塞上移；活塞的 `linearDamping` 用来表达“缓慢过程”。
- 滑轮场景：绳从两端质量到两个地面锚点，再汇到滑轮；`PulleyJoint` 保证绳长约束；质量不同时自然出现一升一降。
- 选择页 4×4 十四个示例；热学/连接体是通用组件，不是题目预置；「从空白画布」仍是主入口。

## 14. v4.7：多过程链与场入口

- 多过程示例用「斜面 → 粗糙水平 → 上坡」的通用链；滑块、地形、摩擦都是可编辑的组件；换几何/摩擦就是新题。
- 世界面板增加「加匀强电场」「加匀强磁场」和对应滑杆；空白画布不必依赖带场示例就能加场。
- 选择页 4×4 + 1 共 15 个示例；「从空白画布」仍是主入口。

## 15. v4.8：多体与交叉场

- 多体碰撞示例：三个等质量球的速度传递；动量/动能判据同屏。
- 正交电磁场示例：E+B 同时作用；世界面板可调 E/B；轨迹是通用求解结果，不是写死的曲线。
- 选择页 4×4 + 1 共 17 个示例；热学/连接体/多过程/多体/交叉场都是组件，不是题目预置。

## 16. v4.9：圆弧链上架

- 圆弧链用 13 段光滑折线近似圆弧，小球从水平段切向进入；轨迹、速度、能量都可观察。

## 19. v5.2：题目优先的入口层级

- **首屏换主角**：从“示例画廊 + 空白画布”改为“题目入口 + 示例参照”。主 CTA「题目 → 建模」用烧橙实心，次 CTA「从空白画布开始」用炭黑；示例卡保留但下移，不再承担主路径。
- **首屏说清三件事**：把题变成能拨的模型；现在只有文字粘贴（图片/拍照后续）；生成不准就直接改——手动编辑是兜底。
- **题目弹层三入口**：`粘贴文字` 可用；`图片识别` / `拍照` 是虚线 disabled，点击只说明“还在做”。下面一行小字把现状说明白，避免用户反复点。
- **兜底路径可见**：底部常驻「手动搭：从空白画布开始」；失败时变橙加粗。生成失败不弹二次确认，错误信息和出口在同一屏。
- **生成后明确“初稿”**：状态条橙色 chip「题目初稿 · 可改」+ 已有「假设」chips，不把生成结果说成答案。
- **小程序**：没有 DOM，用 `wx.showModal({editable:true})` 输入；失败二次弹窗的 confirm 直接 `app.loadBlank()`，这是手机上唯一轻量的兜底路径。
- **截图**：`180-picker-problem-first.png`、`181-problem-sheet.png`、`182-problem-fallback.png`、`184-problem-generated.png`、`185-problem-sheet-mobile.png`、`186-mp-picker-v52.png`。
