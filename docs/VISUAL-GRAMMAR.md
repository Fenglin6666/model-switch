# 视觉语法：外观即语义

> 起点：固定 vs 可移动，不做开关，用外观区分。
> 这条比我原来提的「面板两态开关」好，理由见 §1。顺着这个思路，它其实可以覆盖**所有**物理条件。

---

## 1. 为什么外观比开关好

| | 面板开关 | 外观区分 |
|---|---|---|
| 用户要先知道「有这个概念」 | ✅ 要 | ❌ 不用 |
| 一眼看出当前是什么 | ❌ 要点开面板 | ✅ 直接看到 |
| 上课时能看见 | ❌ 面板占屏 | ✅ 一直在 |
| 改状态 | ✅ 点一下 | ⚠️ 需要一个入口（见 §5） |

**开关是「让用户操作概念」，外观是「让用户看见事实」。**

而且这条与 `DECISIONS.md` §30 的产品原则一致：**只提供情境，不提供怎么讲**——外观是情境的一部分，开关是操作。

---

## 2. 视觉语法表

原则：**不要发明符号，用教材里已有的**。老师认识剖面线、认识 ××、认识「轻」绳。

| 物理条件 | 视觉编码 | 教材依据 | 成本 |
|---|---|---|---|
| **固定** | 接触面外侧画 **45° 剖面线**（间距 6–8px，细线 1px，`inkFaint` 色） | 力学固定端/固定面标准符号 | 低（~30 行） |
| **可移动** | 不画剖面线；与地面留 **1.5px 缝隙**；质量标签 `M` 常显 | 对比「钉住」 | 低（~10 行） |
| **光滑** | 表面线干净（现状） | 光滑面不画纹理 | 0 |
| **粗糙** | 表面线**外侧**挂短斜纹（像刷子，长 5px，间距 5px） | 教材粗糙面画斜线 | 低（~20 行） |
| **轻绳 / 轻杆** | 细线 1.2px，**不标质量** | 「轻」= 不计质量 | 0 |
| **重物** | 描边 2px + 质量标签 | — | 0 |
| **带电** | 体心画 `+` / `−`（小圆 5px 内十字/横杠），红/蓝 | 教材电荷符号 | 低（~10 行） |
| **场作用区域** | 8% 淡填充 + 虚线边界（现状）+ 角落 `E` / `B` 标签 | 教材场区 | 0（已有） |
| **磁场（向里）** | 区域内 **`×` 阵列**（间距 22px） | **教材标准符号** | 中（~30 行 + 缓存） |
| **磁场（向外）** | 区域内 **`·` 阵列** | **教材标准** | 同上 |
| **有界场** | 虚线边界 + 只在场内画 ×/· | 「磁场仅分布于…」 | 同上 |
| **轨道（小球贴轨）** | 轨道线用 `THEME.track` 双线 | — | 0 |

**其中「磁场 ×/·」的性价比最高**：现在 `crossedFields` 场景里磁场只是一个带标签的淡蓝区域，老师看不出方向。加上 ×/· 之后，一眼就是课本图。

## 3. 三条实现规则

### 规则 1：符号画在「接触面外侧」，不侵入物体

剖面线和粗糙纹理都画在物体轮廓**外面**，不覆盖填充。

理由：填充是物体的识别色，侵入会降低可辨识度；而且剖面线在外部才符合教材画法（固定面下方、粗糙面上方）。

### 规则 2：可叠加，不互斥

一个斜面可以同时是「固定 + 粗糙」，所以剖面线和粗糙纹是两个独立通道：

```ts
type SurfaceDeco = {
  fixed?: boolean      // 剖面线
  rough?: boolean      // 短斜纹
}
```

不要做成「一个枚举选一种外观」——那样组合会爆炸。

### 规则 3：不抢注意力

- 剖面线用 `inkFaint`（34% 墨色），不用主题橙
- 主题橙（`accent`）只留给**选中态**和**力箭头**
- 所有装饰线宽 ≤1px，不参与选中高亮

**理由**：这些是「背景信息」，一旦画重了，画面就变成教科书插图，失去「可以拨」的感觉。

## 4. 固定 vs 可移动：具体做法

```ts
// packages/render/src/renderer.ts — drawBody() 里，drawGeometry 之后
if (body.kind === 'static' && showsAsFixed(body)) {
  drawHatchUnder(ctx, camera, geoms, transform)   // 轮廓外侧 45° 剖面线
}
```

**判定 `showsAsFixed`**：
- `kind === 'static'` 一律视为固定（地面、固定斜面、固定的槽）
- `kind === 'rigid' | 'particle'` 一律不画（物块、可移动的槽）

**这就够了**，因为 `kind` 已经表达了「会不会动」。不需要新字段。

**为什么剖面线能让人理解**：教材里「固定在地面上」就是画一排斜线。老师看到斜线 = 钉住了；看到没有斜线 = 可以滑。

**一个额外收益**：现在静态地形和动态物体的唯一区别是「有没有地面阴影」，而这个区别在物体悬空时不成立（阴影离得远）。加剖面线之后，这个语义第一次变得**不依赖阴影**。

## 5. 唯一的缺口：怎么改？

外观解决「它现在是什么」，不解决「我想让它变成另一个」。

现状：**双击循环 地形 → 物体 → 轨道**（README 已有）。问题是这是隐藏知识。

三个选项：

| 选项 | 成本 | 评价 |
|---|---|---|
| 保持双击，什么都不加 | 0 | 老师发现不了 |
| 选中时在物体旁浮一个 **只读徽标**「固定」，双击切换 | ~10 行 | **推荐**：外观负责理解，徽标负责提示「这个可以改」 |
| 面板加两态开关 | ~20 行 | 你已否决，而且违反「外观即语义」 |

**推荐第二个**：徽标不是控件，是一个**提示**。它只在选中时出现，不占常驻空间。

## 5.5 已实现（v5.4）

| 项 | 实现 | 备注 |
|---|---|---|
| 固定剖面线 | `renderer.ts` 的 `drawFixedHatch`：取下轮廓，轮廓外侧画 45° 短划（7px 间距、1px、22% 墨） | `kind === 'static'` 一律画；动态体不画，所以「钉住 / 能滑」不依赖阴影就能分辨 |
| 磁场 ×/· | `drawFields` → `drawMagnetic`：32px 间距阵列，`bz ≥ 0` 画 `·`（向外），`bz < 0` 画 `×`（向里）；左上角标签「B 向外 ·」 | 有 `regionId` 只画在场区内；全场则铺满可视范围（26% 蓝） |
| 电场箭头 | `drawElectric`：104px 间距短箭头，方向取 `vector` | 现在「正交电磁场」一眼能看出 E 和 B 各自的方向 |
| 带电 +/− | `drawChargeSign`：体心 11px 圆 + 十字/横杠，红正蓝负 | 屏幕短边 <16px 不画 |
| 不抢注意力 | 剖面线 22% 墨、场符号 26% 蓝；屏幕短边 <24px 一律不画装饰 | 见 §7 的下限要求 |

**还没做**：粗糙面短斜纹、可移动的 1.5px 缝隙、选中时的「固定」徽标（§5 推荐项）。这三项在文档里是 P1，留到阶段二和约束退化一起做——退化要用同一套外观语言。

## 6. 成本与优先级

| 项 | 人日 | 优先级 | 理由 |
|---|---|---|---|
| 固定剖面线 + 可移动缝隙 | 0.5 | **P0** | 你提的这条，且影响「半圆槽」这个招牌场景 |
| 磁场 ×/· 阵列 | 0.5 | **P0** | 磁场占计算题 21%，现在完全看不出方向 |
| 粗糙面短斜纹 | 0.5 | P1 | 光滑/粗糙是题干最高频的条件之一 |
| 带电 +/− 符号 | 0.2 | P1 | 便宜，且让「带电小球」一眼可辨 |
| 选中时角色徽标 | 0.2 | P1 | 补 §5 的缺口 |
| 轻绳/重物线宽区分 | 0.1 | P2 | 已经在 `appearance.style = 'thin'` 里有一半 |

**合计约 2 人日，全部是渲染层改动，不碰物理、不碰序列化、不影响 `p1.` 分享串。**

## 7. 一个风险

**外观区分在「看不清」时会失效。**

- 小屏幕上剖面线间距 6px 可能糊成一团 → 间距要按 `camera.pixelScale` 自适应，不要用固定像素
- 缩得很小的时候，剖面线会变成灰块 → 低于某个体素阈值时**不画**（宁可没有，不要脏）

**所以实现时给一个下限**：屏幕上的物体短边 < 24px 时，不画任何装饰。

---

## 8. 这条原则还能用在哪

「外观即语义」不止用于固定/可移动。它其实是**把题干的形容词变成视觉**：

| 题干说 | 视觉给 |
|---|---|
| 「光滑斜面」 | 干净表面线 |
| 「粗糙水平面」 | 表面挂斜纹 |
| 「轻绳」 | 细线、无质量标 |
| 「带电小球」 | 体心 +/− |
| 「匀强磁场垂直纸面向里」 | × 阵列 |
| 「槽固定」 | 底部剖面线 |
| 「不计空气阻力」 | 无阻力箭头（现状：无） |
| 「恰好不下滑」 | 由判据 chip 表达（现状） |

**判据那一行值得注意**：`恰好` 是过程条件，不是外观——它只能靠「播放后判据翻转」表达。这也说明外观有边界：**静态条件靠外观，过程条件靠判据**。两者不要混。
